GOVT VACANCY WEBSITE - BEGINNER VERSION

How to use:
1. Upload all four files to one GitHub repository.
2. Keep index.html as the homepage.
3. Open GitHub Settings > Pages and publish the main branch.
4. Replace the demo vacancy information with verified official information.
5. Replace the demo buttons with the correct official recruitment URLs.
